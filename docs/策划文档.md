  - Web Audio 音效与震动反馈，可在设置面板开关。

## 1. 产品概述

浏览器多人协作打砖块：多名玩家各自控制一条挡板，共用一颗球与一面砖墙，生命与分数由服务器同步。适合局域网或部署在同一主机上的好友通过同一 URL 加入。

---

## 2. 核心规则

| 项目 | 说明 |
|------|------|
| 人数 | 1～4 人同房间 |
| 生命 | 初始 10 条命；球落底扣 1；为 0 时 `gameover`；每累计 100 分奖励 1 条命 |
| 胜利 | 清空所有砖块 → `win` |
| 得分 | 每击碎一块砖 **+10**，加给**当前球最后一次击中挡板（最后击板者）**的玩家；发球时归属发球点所在玩家 |
| 道具 | 击碎砖块按概率掉落：**W** 加宽挡板（1.5 倍，持续 10 秒）、**P** 加分（+50）、**M** 多球（额外生成 2 颗球，球数上限 12） |

**多球与得分归属：** 场上可同时存在多颗球，每颗球独立判定与挡板、砖块的碰撞；击碎砖块的得分统一归属「该球最后一次击中挡板」的玩家，发球时归属发球点所在玩家。多球全部落底后才扣除 1 条生命并重新发球。每名玩家累计得分每达到 100 分（含道具加分）奖励 1 条生命。

**状态机（服务器权威）：**
`waiting` →（开始）→ `playing` ↔ `paused` → `gameover` / `win`；`restart` 重置生命、砖块、分数与道具后直接开启新一局 `playing`。

---

## 3. 操作说明

- **移动挡板：** ← → 或 A D；鼠标在画布上移动同步控制（与键盘二选一或组合，以服务器每帧合并为准）。
- **暂停：** 空格或界面「暂停」；暂停时主菜单按钮文案为「继续游戏」，发送 `pause` 切换。
- **开始：** 至少一名玩家在房间内，点击「开始游戏」发送 `start`。
- **再玩一局：** 游戏结束或通关后点击「再玩一次」发送 `restart`。
- **断线：** 自动重连（退避）；亦可点击「重连」立即尝试新的连接与加入流程。

---

## 4. 技术架构（简述）

- **HTTP：** 提供 `index.html`、`style.css`、`game.js`、`/config.js`、图标与背景图；`/health` 端点返回 `status`、`version`、玩家数与运行时长，供部署平台健康检查使用。
- **纯逻辑层：** `game-core.js` 集中 `CONFIG`、规则、状态创建与步进、状态序列化；`server.js` 负责连接治理、入参校验与网络 IO，纯逻辑可被 `node:test` 直接测试。
- **WebSocket：** 客户端发送 `join` / `input` / `command` / `ping`；服务器广播 `gameState`（含球、砖块、玩家挡板与分数、生命、状态）与 `fullState`（全量对账）。
- **模拟与广播：** 球运动、挡板移动、碰撞与得分均在服务端 `stepGame`（约 8ms tick）中计算；状态广播降频到约 30Hz（33ms）且仅在状态变脏时下发，客户端仅渲染、插值与上报输入。

## 5. 非目标与限制（当前版本）

- 未实现账号与跨房间匹配；反作弊加固亦未实现。
- 本地「最高分」为浏览器 `localStorage`，仅本机、本域名有效。
- 单进程单房间：所有连接共享同一 `game` 状态。

## 7. 后续版本规划（v3.0 暂定）

### 7.1 核心机制
- **每名玩家有独立的球**（初始1个），所有玩家挡板可击打任意球。
- **得分与淘汰**：球飞出底部后，最后击打者得分。玩家无球时则被淘汰，从游戏中移除（挡板消失）。
- **无尽随机关卡**：关卡随机生成（Rougelike 风格），包含不同的砖块数量、排列和颜色分布，难度随进度递增。

### 7.2 奖励机制
- 玩家得分每达到 100 分，奖励 1 颗新球。
- 新球从该玩家挡板上方发射。
- 奖励后该玩家的球数上限 +1，并立即生成一个 active 球。

### 7.3 数据模型预想
```js
Player {
    id, color, x, targetX, score, 
    balls: [{x, y, dx, dy, lastHitter}],
    ballsRemaining: 1, 
    maxBalls: 1 + Math.floor(score/100)
}

Ball {
    x, y, dx, dy, lastHitter: playerId
}
```

- 随机砖块生成算法与无尽模式难度曲线
- 玩家淘汰机制与奖励系统
